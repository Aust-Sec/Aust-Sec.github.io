NOT A CLUB.
A LAB.

02 / 我们做什么

WHAT WE DO

01

CTF

以赛促学

Web / Pwn / Reverse / Crypto / Misc。从基础题目开始，理解漏洞、程序与系统背后的原理。

02

SRC

漏洞挖掘

资产发现、漏洞复现、报告撰写。在合法授权的前提下，了解真实的安全研究流程。

03

SECURITY

技术研究

Web 安全、渗透测试、逆向工程、二进制安全、安全开发，以及 AI × Security 等交叉方向。

04

SIGNAL

信息与资源

比赛信息、学习路线、优质项目、安全社区、工具资源、行业动态。这一块是我们最想做成特色的。

所有漏洞挖掘与测试，仅在合法授权范围内进行。
