# AustSec

安徽理工大学网络空间安全协会学生自建站点。

> 本站由协会学生成员自主设计、建设与维护，用于介绍 AustSec、分享网络安全学习方向并发布招新信息。本站不是安徽理工大学官方站点。

访问网站：[https://austsec.github.io/](https://austsec.github.io/)

## 关于 AustSec

AustSec 成立于 2026 年，是由安徽理工大学网络安全爱好者共同组建的学生社团。

我们希望认识更多对网络安全感兴趣的朋友，从基础知识开始，一起交流、参加比赛、尝试项目，并把学习中收集到的信息和资源开放分享。我们也期待结识愿意交流和指导我们的老师、学长与师傅。

我们目前关注的方向包括：

- **CTF**：Web、Pwn、Reverse、Crypto、Misc 等方向，以赛促学。
- **SRC**：资产梳理、漏洞复现、报告撰写与安全研究流程。
- **Security**：Web 安全、渗透测试、逆向工程、二进制安全、安全开发及 AI × Security。
- **Signal**：比赛信息、学习路线、工具资源、优质项目与行业动态。

## 2026 招新

我们正在寻找愿意一起学习、分享与建设 AustSec 的伙伴。

无论你刚开始了解网络安全，还是已经有自己的学习方向，都欢迎加入交流。我们希望大家保有好奇心，在各自的节奏里持续学习，也愿意把所知分享给彼此。

加入后可以和大家一起：

- 从 Linux、Git、计算机网络和编程基础开始学习；
- 尝试 CTF 入门题，逐渐找到感兴趣的方向；
- 交流学习路线、工具和比赛信息；
- 参与题解、工具、资料整理及开源项目；
- 认识志同道合的朋友，也向愿意分享经验的师傅们请教；
- 一起参与 AustSec 的内容建设与开源协作。
